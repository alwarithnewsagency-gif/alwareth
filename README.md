# موقع وكالة الوارث نيوز — نسخة GitHub

الموقع يقرأ الأخبار من الملف `content/news.json`، ولوحة النشر في `/admin` تحفظ كل خبر وصورته مباشرة في مستودع GitHub.

## محتويات المجلد
- `index.html` : الموقع نفسه (نفس التصميم السابق).
- `admin/` : لوحة النشر (Sveltia CMS) وملف الإعداد `config.yml`.
- `content/news.json` : الأخبار (تتعدّل من اللوحة ولا حاجة لتعديله يدويًا).
- `images/` : الشعار وصور الأخبار (`images/uploads`).

## خطوات التشغيل (مرة واحدة)

**1. أنشئ مستودعًا على GitHub**
من github.com اضغط New repository، اختر اسمًا (مثلًا `alwareth-news`) وSelect Public، ثم Create.

**2. ارفع الملفات**
داخل المستودع اضغط Add file ثم Upload files، واسحب كل محتويات هذا المجلد (الملفات والمجلدات `admin` و`content` و`images`)، ثم Commit changes.

**3. فعّل الموقع**
Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` و `/ (root)` ← Save.
بعد دقيقة يظهر رابط الموقع: `https://اسم-حسابك.github.io/اسم-المستودع/`

**4. اربط اللوحة بالمستودع**
افتح الملف `admin/config.yml` من GitHub (أيقونة القلم) وغيّر السطر:
`repo: YOUR-USERNAME/YOUR-REPO`
إلى اسم حسابك واسم المستودع، مثال: `repo: ali-news/alwareth-news` ثم Commit.

**5. أنشئ مفتاح الدخول (Token)**
GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token:
- Repository access: Only select repositories ← اختر مستودع الموقع فقط.
- Permissions ← Repository permissions ← **Contents: Read and write**.
- انسخ المفتاح فور ظهوره (لا يظهر مرة ثانية).

**6. ادخل إلى لوحة النشر**
افتح `https://اسم-حسابك.github.io/اسم-المستودع/admin/` واختر تسجيل الدخول بالمفتاح (Token) والصق المفتاح.

## نشر خبر
الأخبار ← أخبار الموقع ← أضف خبرًا ← املأ العنوان والقسم والصورة والنص ← Save ثم Publish.
يظهر الخبر في الموقع خلال دقيقة إلى دقيقتين.
- **خبر عاجل:** فعّل خيار "خبر عاجل" ليظهر في الشريط الأحمر.
- **إخفاء خبر مؤقتًا:** أزل علامة "منشور".
- **حذف أو تعديل:** من القائمة نفسها.

## ملاحظات أمان
- المفتاح يبقى في متصفحك أنت فقط ولا يوجد داخل كود الموقع. لا تشاركه مع أحد، وإن ضاع احذفه من GitHub وأنشئ غيره.
- كل من يملك مفتاحًا بصلاحية الكتابة يستطيع النشر. لإضافة محرر آخر، أضفه Collaborator على المستودع ثم يُنشئ مفتاحه الخاص.
- المستودع العام يعني أن الأخبار والصور مرئية للجميع، وهذا هو المقصود في موقع أخبار.
- الصور تتحول تلقائيًا إلى WebP لتخفيف الحجم. يفضَّل ألا تتجاوز الصورة الأصلية 3 ميغابايت.

## إن أردت دومينًا خاصًا
Settings ← Pages ← Custom domain، وبعدها لا تحتاج تغيير شيء في الملفات.
